# Lyapunov

Lyapunov is a proposed desktop application for saving an activity as a card and returning to its useful applications, windows, folders, and documents later. The primary interaction is a stack of selectable cards with a Liquid Glass visual direction.

The project is currently a concept. No application, repository, logo, license, or release has been created. The complete product brief and current decisions are in [PROJECT_BRIEF.md](PROJECT_BRIEF.md).

The visual direction is documented in the private `Chaos-Tic/Chaostic-Skins` repository under `skins/liquid-glass/`. Lyapunov will have its own name and icon; Lorenz is a visual family reference.
