# Accessibility

We aim to make Lyapunov usable through clear interaction and to improve accessibility as barriers are identified. We do not claim conformance to a particular accessibility standard.

## Current support and limitations

Lyapunov includes keyboard controls for capturing and resuming spaces, along with reduce-motion and reduce-transparency preferences. The [user guide](docs/USER_GUIDE.md) describes these options. Integration and window-management capabilities vary by platform.

Compatibility with every assistive technology, platform and workflow has not been verified. Consult the project documentation for tested platforms and known limitations.

## Report a barrier

Please [open an issue](https://github.com/Chaos-Tic/Lyapunov/issues/new/choose) and describe the task, the barrier, the application version, operating system, desktop environment and assistive technology if relevant. Avoid including personal or confidential information. Security vulnerabilities should be reported privately as described in [SECURITY.md](SECURITY.md).
