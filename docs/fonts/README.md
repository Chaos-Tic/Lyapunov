# Fonts

[Geist](https://github.com/vercel/geist-font) is the Chaos-Tic display and
monospace family. The static TTFs here are vendored so `scripts/render-docs.sh`
can flatten the README banners' text to vector paths **offline**: no font is
installed on the host and nothing is fetched when the README is viewed.

| File | Family |
| --- | --- |
| `Geist-Regular.ttf`, `Geist-SemiBold.ttf` | Geist (sans) |
| `GeistMono-Regular.ttf` | Geist Mono |
